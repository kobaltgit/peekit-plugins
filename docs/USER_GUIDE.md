# Руководство пользователя PeekIt Plugins

Это руководство описывает, как устанавливать, настраивать, использовать и удалять плагины расширения форматов для утилиты **[PeekIt](https://github.com/kobaltgit/peekit)** в Windows 10 и 11.

---

## Что такое плагины PeekIt?

По умолчанию PeekIt поддерживает базовый набор форматов операционной системы: популярные растровые изображения (PNG, JPG, WebP), аудио, видео и текстовые файлы.

Плагины в формате **`.pkit`** добавляют поддержку специализированных и профессиональных форматов:
* **3D-модели:** `.stl`, `.obj`, `.gltf`, `.glb`, `.ply` (интерактивный 3D-вьюпорт).
* **Офисные документы:** `.docx`, `.xlsx`, `.pptx`, `.csv`, `.tsv`, `.ods`.
* **Векторная графика и дизайн:** `.svg`, `.psd`, `.ai`, `.eps`, `.dds`.
* **Типографика и шрифты:** `.ttf`, `.otf`, `.woff`, `.woff2` (таблицы глифов, панграммы).
* **Электронные книги и архивы:** `.epub`, `.fb2`, `.zip`, `.tar`, `.gz`, `.apk`.
* **Разработка и базы данных:** `.ipynb` (Jupyter Notebooks), `.sqlite`, `.db`.

Все плагины работают на 100% локально (без интернета) и не нагружают память компьютера в фоновом режиме.

## Способы установки

### Способ 1. Установка из встроенного каталога (Рекомендуется)

1. Откройте **Параметры PeekIt** (правый клик по иконке в трее $\rightarrow$ *Настройки*).
2. Перейдите на вкладку **Плагины**.
3. Найдите нужный плагин в каталоге и нажмите **Установить**.
4. Плагин загрузится, распакуется и активируется автоматически без перезапуска приложения.

### Способ 2. Drag & Drop файла `.pkit`

1. Скачайте файл плагина с расширением `.pkit` из раздела [Releases](https://github.com/kobaltgit/peekit-plugins/releases) или с официального сайта [каталога плагинов](https://kobaltgit.github.io/peekit-plugins/).
2. Перетащите скачанный `.pkit` файл прямо в открытое окно предварительного просмотра PeekIt или в окно настроек.
3. Подтвердите установку во всплывающем системном уведомлении.

### Способ 3. Ручная установка

1. Нажмите комбинацию клавиш `Win + R`, введите:
   ```text
   %APPDATA%\PeekIt\plugins
   ```
   и нажмите Enter.  
   *(Если вы используете портативную версию PeekIt, откройте папку `plugins/` рядом с `PeekIt.exe`).*
2. Создайте подпапку для плагина (например, `peekit-plugin-svg`).
3. Распакуйте содержимое файла `.pkit` (это стандартный ZIP-архив) в созданную подпапку так, чтобы файл `manifest.json` лежал непосредственно в ней.
4. Плагин будет автоматически обнаружен при следующем открытии соответствующего файла.

## Работа с файлами и горячие клавиши

* **Пробел (Space):** Мгновенно открыть окно предварительного просмотра для выбранного в Проводнике Windows файла. Повторное нажатие Пробела закрывает окно.
* **Esc:** Закрыть окно предварительного просмотра.
* **Стрелки (Вверх / Вниз / Влево / Вправо):** Переключение на соседний файл в текущей папке Проводника прямо во время открытого предпросмотра.
* **Ctrl + Колесо мыши / `+` / `-`:** Масштабирование контента (документов, изображений, векторных чертежей).
* **Ctrl + 0:** Сброс масштаба и центрирование документа в окне.
* **Кнопка RU/EN в шапке окна:** Переключение языка интерфейса плагина.

## Управление ассоциациями файлов

Если в системе установлено несколько плагинов, поддерживающих одно и то же расширение (например, `.svg` поддерживается стандартным просмотрщиком и расширенной студией):
1. Откройте **Параметры** $\rightarrow$ **Ассоциации файлов**.
2. В списке расширений выберите желаемый плагин по умолчанию.

---

## Удаление плагина

1. Откройте **Параметры PeekIt** $\rightarrow$ **Плагины**.
2. Перейдите на вкладку **Установленные**.
3. Нажмите кнопку корзины (или **Удалить**) напротив нужного плагина.
4. Файлы плагина будут полностью очищены с диска.

## Решение проблем (Troubleshooting & FAQ)

#### Окно предпросмотра открывается белым или пустым
Убедитесь, что в вашей системе установлен компонент **Microsoft Edge WebView2 Runtime** (в Windows 10/11 он обычно предустановлен). Если компонент повреждён, скачайте актуальный установщик с официального сайта Microsoft.

#### Плагин не реагирует на нажатие Пробела
1. Проверьте, ассоциировано ли расширение файла с плагином в настройках PeekIt.
2. Проверьте, не заблокирован ли скачанный файл системой безопасности Windows (правый клик по файлу $\rightarrow$ *Свойства* $\rightarrow$ флажок *Разблокировать*).

#### Где посмотреть журнал ошибок?
Логи работы PeekIt и плагинов сохраняются по адресу:
```text
%APPDATA%\PeekIt\logs
```
