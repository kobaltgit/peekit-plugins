# 🔤 PeekIt Font Viewer Plugin

Референсный плагин для [PeekIt](https://github.com/kobaltgit/PeekIt), обеспечивающий интерактивный просмотр шрифтов `.ttf`, `.otf`, `.woff`, `.woff2`.

## ✨ Возможности
* Автоматическая регистрация шрифта в браузере через `FontFace API`.
* Ползунок изменения кегля (12px – 96px).
* Интерактивное поле ввода произвольного текста.
* Таблица глифов и панграммы (кириллица, латиница, цифры).
* Поддержка Fluent Design тем (светлая и тёмная).
