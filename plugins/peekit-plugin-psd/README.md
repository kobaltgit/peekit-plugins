# 🖌️ PeekIt Adobe Photoshop Viewer Plugin

Официальный плагин для быстрого предварительного просмотра файлов Adobe Photoshop (`.psd`) в **PeekIt**.

## Возможности
- **Композитный рендеринг**: мгновенная отрисовка объединенного изображения Photoshop со 100% точностью.
- **Поддержка прозрачности**: шахматная сетка в стиле Photoshop.
- **Инспектор слоев**: просмотр дерева слоев, их видимости, режимов наложения и непрозрачности.
- **Интерактивный просмотр**: масштабирование колесиком мыши (Zoom In/Out, Fit, 100%) и панорамирование перетаскиванием (Pan & Drag).
- **Информационная панель**: размеры в пикселях, цветовой режим (RGB, Grayscale и др.), глубина цвета и количество слоев.
- **100% Offline**: библиотека `ag-psd` встроена напрямую в `index.html`. Никаких внешних запросов.
