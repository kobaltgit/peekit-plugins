# 📐 PeekIt Encapsulated PostScript (EPS) Viewer Plugin

Официальный плагин для быстрого предварительного просмотра векторных и полиграфических файлов Encapsulated PostScript (`.eps`) в **PeekIt**.

## Возможности
- **Двухуровневый гибридный рендеринг**:
  - **Мгновенный Fast-path**: извлечение встроенного растрового превью высокого разрешения (TIFF/EPSI из DOS EPS заголовка) за 5–10 мс.
  - **Векторный PostScript интерпретатор**: прямое исполнение стека команд PostScript (линии, кривые Безье, заливки, CMYK/RGB цвета) через встроенный движок `UDOC.js` на чистом JavaScript.
- **Информационная панель метаданных**:
  - Физические размеры макета (BoundingBox в пунктах pt и пикселях).
  - Программа-создатель (`%%Creator:` Adobe Illustrator, CorelDRAW, InDesign, Matplotlib и др.).
  - Источник рендеринга (бейдж «TIFF Превью» или «Векторный рендер»).
- **Интерактивная навигация**:
  - Плавное масштабирование (Zoom In/Out, Fit по размеру окна, 100% реальный размер).
  - Панорамирование перетаскиванием (Pan & Drag).
  - Адаптивная сетка прозрачности (шахматка), подстраивающаяся под светлую и темную тему оформления.
- **100% Offline и Zero-Memory Overhead**:
  - Все декодеры (`UTIF.js`, `pako`, `UDOC.js`, `FromPS.js`, `ToContext2D.js`) встроены внутрь плагина. Никаких внешних утилит (Ghostscript не требуется) и сетевых запросов.
  - Виртуальный холст (Viewport Canvas) отрисовывает только видимую область окна, исключая утечки оперативной и видеопамяти.
