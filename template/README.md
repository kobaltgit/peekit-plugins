# PeekIt Plugin Starter Template

Стартовый шаблон для создания плагинов к [PeekIt](https://github.com/kobaltgit/PeekIt).

## 🛠 Запуск в режиме разработки
```bash
npm install
npm run dev
```
Шаблон содержит встроенный Mock-модуль, что позволяет отлаживать интерфейс прямо в браузере (Chrome / Edge) без запуска PeekIt.

## 📦 Сборка плагина
```bash
npm run build
```
Собранные файлы скопируйте в `%APPDATA%\Peekit\plugins\<ваш-plugin-id>\`.
